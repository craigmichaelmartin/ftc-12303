# FTC 12303 · BIOBUZZ 2026-27 docs

| Folder | What's in it |
|---|---|
| [`plan/`](plan/00-master-plan.md) | The team plan: master plan and timeline, scoring, AUTO, TELEOP, endgame, robot tuning, software, testing and practice, match day and scouting, rules cheat sheet. **Start with `plan/00-master-plan.md`.** |
| [`playbook/`](playbook/biobuzz-playbook.html) | Local copy of the one-page playbook (interactive field map). Open it in a browser. Diagrams render only in the live version. |
| [`research/`](research/) | The research behind the plan. R1 rules, R2 field geometry (CAD-derived coordinates), R3 launch physics, R4 early-season data and the Michigan calendar, R5 hardware, R6 software, R7 robot audit, [R8 the robot as built](research/R8-robot-v2.md) (what the coach's video shows, what the coach confirmed, what is still unknown). **R5 and R7 describe the earlier turret version of the robot** and are kept as the record of that design; the plan and the code are written for the robot in R8. Each `*.verify.md` is an independent fact-check; where it corrects the report, the fact-check wins. R7's fact-check, [`R7-robot-audit.verify.md`](research/R7-robot-audit.verify.md), lists which R7 claims hold, which are corrected and which had to be measured on that robot. `strategy-brief.md` records the strategy decisions, with a decision record for design changes. Paths starting with `scratch/` name working scripts and downloads that were not kept, `PXL_….jpg` names are the team's photos of the turret version, and R8 cites the coach's video by timestamp (photos and video are not in the repo). |

Robot code setup and the tuning order are in `TeamCode/src/main/java/org/firstinspires/ftc/teamcode/README-12303.md`. The plan docs describe what that code does; where they disagree, the code is what the robot will do.
